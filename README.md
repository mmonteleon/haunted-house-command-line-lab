# Haunted House Terminal Quest

Welcome, Investigator! You are trapped inside a haunted mansion filled with hidden passages, deep closets, drawers, and locked trunks.

To break the curse and escape, you must explore the mansion, inspect hidden files, follow clues, and move or destroy items.

---

## Navigation Tips for Multi-Level Directories
- pwd — Shows your current exact path in the mansion
- ls — Look around the current directory
- ls -a — Find hidden files (. files)
- cd folder — Move deeper into a room or item
- cd .. — Move up one directory level
- cd ../.. — Move up two directory levels
- cat file — Read a file or clue
- mv source destination — Move or rename an item
- rm file — Delete/destroy cursed items

---

## Your Objectives
1. Escape the mansion by finding the silver_key and bringing it back to the foyer/.
2. Destroy the 2 cursed items hidden somewhere in the house using rm.
3. Find the locked chest in the mansion and unlock it by renaming its padlock file.

Start your investigation by entering the rooms using cd!
